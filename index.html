El Sistema Modular

Un diseño estructural pensado para la máxima eficiencia y resistencia sobre cualquier superficie.

Concepto Modular Adaptable

El sistema se encastra y crece de forma tridimensional a partir de un módulo inicial, permitiendo cualquier distribución superficial de manera robusta.

Medidas Base de Alta Precisión

Cada módulo inicial cuenta con unas dimensiones estándar de 1,05 x 0,80 metros, optimizando el espacio y facilitando el cálculo de cargas.

Adaptabilidad Infinita

Al multiplicar los módulos iniciales, logramos medidas exactas que se adaptan con absoluta facilidad a las exigencias y dimensiones de cualquier evento.

Especificaciones Técnicas

Materiales y terminaciones bajo las normas de seguridad más estrictas para el mercado corporativo.

Materiales Estructurales

  • Caño de hierro estructural de alta resistencia.
  • Tratamiento zincado completo para evitar corrosión.
  • Piso de terciado fenólico de 25 mm de espesor real.

Terminaciones Estéticas

  • Frentín y pollera perimetral en color negro mate.
  • Alfombrados de alta densidad en colores a definir.
  • Terminación impecable, prolija y sin bordes expuestos.

Rango de Alturas

  • Nivelación ajustable desde un mínimo de 0,30 metros.
  • Altura máxima de hasta 2,00 metros para salones cerrados.
  • Patas regulables para corregir desniveles del suelo.
